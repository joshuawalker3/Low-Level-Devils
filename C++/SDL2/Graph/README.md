# SDL2 Selection Sort

## Project Description
This project will generate 800 rectangles of random heights. It will display these on the screen and then visually sort them in real time. 

## Required Libraries
- SDL2

## Required Tools
- Make

## Build
0. If on windows, update makefile to include .exe extension for output

1. Compile the application
```bash
make
```
2. Run the application
```bash
./main
```
